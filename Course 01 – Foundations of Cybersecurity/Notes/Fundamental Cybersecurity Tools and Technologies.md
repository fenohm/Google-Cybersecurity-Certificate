# Herramientas y tecnologías fundamentales en Ciberseguridad

## Programación

La programación permite crear instrucciones para automatizar tareas y optimizar procesos de seguridad.

### Python

* Automatiza tareas repetitivas.
* Reduce el riesgo de errores humanos.
* Es uno de los lenguajes más utilizados en ciberseguridad para análisis, monitoreo y automatización.

### SQL (Structured Query Language)

* Permite crear y consultar bases de datos.
* Facilita la búsqueda y análisis de grandes volúmenes de información.

---

## Sistemas Operativos

El sistema operativo actúa como intermediario entre el usuario y el hardware.

Los más utilizados son:

* **Linux:** Sistema de código abierto ampliamente utilizado en servidores y ciberseguridad.
* **Windows:** Muy común en entornos empresariales.
* **macOS:** Basado en Unix y utilizado en equipos Apple.

En Linux es común trabajar mediante una **Interfaz de Línea de Comandos (CLI)**, utilizando comandos para administrar el sistema.

---

## Vulnerabilidades Web

Una vulnerabilidad web es una debilidad en una aplicación que puede ser explotada para:

* Obtener acceso no autorizado.
* Robar información.
* Instalar software malicioso.

Como referencia para conocer las vulnerabilidades más críticas existe el **OWASP Top 10**, uno de los principales estándares en seguridad de aplicaciones web.

---

## Software Antivirus

El software antivirus protege los equipos mediante la:

* Detección de malware.
* Prevención de infecciones.
* Eliminación de software malicioso.

Su función es analizar archivos y procesos en busca de comportamientos sospechosos.

---

## Sistema de Detección de Intrusiones (IDS)

Un **IDS (Intrusion Detection System)** supervisa la actividad de una red o sistema para detectar posibles ataques.

Sus funciones incluyen:

* Monitorear el tráfico de red.
* Detectar accesos no autorizados.
* Generar alertas ante actividades sospechosas.

---

## Encriptación

La encriptación protege la confidencialidad de la información transformando datos legibles (**texto plano**) en datos cifrados (**texto cifrado**).

**Objetivo principal:**

* Impedir que usuarios no autorizados puedan leer la información.

---

## Pruebas de Penetración (Pen Testing)

Las pruebas de penetración consisten en realizar ataques controlados sobre sistemas, aplicaciones o redes para identificar vulnerabilidades antes de que sean explotadas por un atacante.

Sus principales objetivos son:

* Detectar debilidades de seguridad.
* Evaluar riesgos.
* Mejorar la protección de la infraestructura.

---

# Conclusión

El dominio de herramientas como Python, SQL, Linux, IDS, antivirus y técnicas como la encriptación y las pruebas de penetración constituye una base esencial para cualquier profesional de la ciberseguridad. Estas tecnologías permiten prevenir, detectar y responder de forma eficaz ante amenazas informáticas.
