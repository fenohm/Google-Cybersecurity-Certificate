# Glossary - Course 04
---

## A

### Absolute file path

Ruta completa de un archivo o directorio, comenzando desde el directorio raíz (`/`).

### Application

Programa diseñado para realizar una tarea específica dentro de un sistema informático.

### Argument (Linux)

Información específica que se proporciona a un comando para indicar sobre qué elemento debe operar o qué acción debe realizar.

### Authentication

Proceso mediante el cual se verifica la identidad de una persona, usuario o sistema.

### Authorization

Proceso de determinar y otorgar los permisos necesarios para acceder a determinados recursos de un sistema.

---

## B

### Bash

Shell y lenguaje de comandos ampliamente utilizado en Linux. Es el shell predeterminado en muchas distribuciones.

### Basic Input/Output System (BIOS)

Firmware almacenado en un chip que contiene las instrucciones necesarias para iniciar el hardware y comenzar el proceso de arranque del sistema operativo. Es común en sistemas más antiguos.

### Bootloader

Programa encargado de iniciar el sistema operativo durante el proceso de arranque del computador.

---

## C

### CentOS

Distribución de Linux de código abierto relacionada estrechamente con Red Hat Enterprise Linux (RHEL).

### Central Processing Unit (CPU)

Procesador principal de un computador, encargado de ejecutar instrucciones y realizar las tareas generales de procesamiento.

### Command

Instrucción que indica al computador qué acción debe realizar.

### Command-line interface (CLI)

Interfaz de usuario basada en texto que permite interactuar con el computador mediante comandos.

---

## D

### Database

Colección organizada de información o datos que puede ser almacenada, consultada y administrada.

### Date and time data

Datos que representan una fecha, una hora o ambas.

### Digital forensics

Práctica de recopilar, preservar y analizar datos digitales para determinar qué ocurrió durante o después de un incidente de seguridad.

### Directory

Estructura utilizada para organizar y almacenar referencias a archivos y otros directorios.

### Distributions

Diferentes versiones o variantes de un sistema operativo Linux, que pueden incluir distintos entornos, herramientas y configuraciones.

---

## E

### Exclusive operator

Operador que realiza una comparación sin incluir el valor utilizado como límite.

**Ejemplo:**

```sql
WHERE age > 18
```

Esta condición selecciona valores mayores que `18`, pero no incluye `18`.

---

## F

### File path

Ubicación de un archivo o directorio dentro del sistema de archivos.

### Filesystem Hierarchy Standard (FHS)

Estándar que define la estructura y organización de directorios utilizada por los sistemas Linux.

### Filtering

Proceso de seleccionar únicamente los datos que cumplen determinadas condiciones.

### Foreign key

Columna de una tabla que hace referencia a una **Primary key** de otra tabla y permite establecer una relación entre ambas.

---

## G

### Graphical user interface (GUI)

Interfaz de usuario que utiliza elementos gráficos, como ventanas, iconos, menús y botones, para interactuar con el computador.

---

## H

### Hard drive

Componente de almacenamiento utilizado para guardar datos de forma permanente o a largo plazo.

### Hardware

Conjunto de componentes físicos de un computador, como CPU, RAM, disco de almacenamiento y dispositivos periféricos.

---

## I

### Inclusive operator

Operador que incluye el valor utilizado como límite en una comparación.

**Ejemplo:**

```sql
WHERE age >= 18
```

Esta condición incluye los valores iguales a `18` y también los mayores.

### Internal hardware

Componentes físicos instalados dentro del computador que son necesarios para su funcionamiento, como la CPU, RAM, placa madre y dispositivos de almacenamiento.

---

## K

### Kali Linux™

Distribución de Linux de código abierto ampliamente utilizada en el ámbito de la ciberseguridad, especialmente para pruebas de penetración, análisis de seguridad y análisis forense.

### Kernel

Componente central del sistema operativo Linux encargado de administrar recursos como procesos, memoria, dispositivos y comunicación entre el hardware y el software.

---

## L

### Legacy operating system

Sistema operativo considerado obsoleto o desactualizado, pero que todavía puede encontrarse en uso.

### Linux

Sistema operativo de código abierto basado en el kernel Linux y utilizado en servidores, computadores personales, dispositivos y entornos de ciberseguridad.

### Log

Registro de eventos generados por sistemas, aplicaciones o dispositivos. Puede utilizarse para monitorear actividades, detectar problemas e investigar incidentes de seguridad.

---

## N

### nano

Editor de texto basado en línea de comandos, disponible de forma predeterminada en muchas distribuciones Linux.

### Numeric data

Datos que están compuestos por valores numéricos y que pueden utilizarse en operaciones matemáticas o comparaciones.

---

## O

### Operating system (OS)

Software que actúa como intermediario entre el hardware del computador, las aplicaciones y el usuario, administrando los recursos del sistema.

### Operator

Símbolo o palabra clave que representa una operación o comparación dentro de un lenguaje de programación o consulta.

### Options

Parámetros utilizados para modificar el comportamiento de un comando.

**Ejemplo:**

```bash
ls -l
```

En este caso, `-l` es una opción que modifica la forma en que `ls` muestra la información.

---

## P

### Package

Unidad de software que contiene los archivos necesarios para instalar una aplicación o componente del sistema.

### Package manager

Herramienta utilizada para instalar, actualizar, administrar y eliminar paquetes o aplicaciones.

### Parrot

Distribución de Linux de código abierto orientada principalmente a tareas de seguridad, privacidad, desarrollo y análisis.

### Penetration test (pen test)

Prueba de seguridad que simula un ataque para identificar vulnerabilidades en sistemas, redes, sitios web, aplicaciones o procesos.

### Peripheral devices

Componentes de hardware conectados al computador y controlados por el sistema, como teclados, ratones, impresoras y dispositivos externos.

### Permissions

Reglas que determinan qué acciones puede realizar un usuario o grupo sobre un archivo o directorio, como leer, modificar o ejecutar.

### Primary key

Columna utilizada para identificar de forma única cada registro de una tabla. Cada valor debe ser único y no debe repetirse.

### Principle of least privilege

Principio de seguridad que establece que cada usuario, proceso o sistema debe recibir únicamente los permisos y accesos mínimos necesarios para realizar una tarea.

---

## Q

### Query

Solicitud realizada a una base de datos para obtener información de una tabla o de varias tablas relacionadas.

**Ejemplo:**

```sql
SELECT username
FROM users;
```

---

## R

### Random Access Memory (RAM)

Memoria utilizada por el computador para almacenar temporalmente los datos y programas que están siendo utilizados. Es una memoria de corto plazo.

### Red Hat® Enterprise Linux®

Distribución de Linux orientada al entorno empresarial, desarrollada para proporcionar estabilidad, seguridad y soporte para organizaciones.

### Relational database

Base de datos estructurada mediante tablas relacionadas entre sí utilizando columnas comunes, como claves primarias y foráneas.

### Relative file path

Ruta de un archivo o directorio que se expresa tomando como referencia el directorio actual del usuario.

### Root directory

Directorio de nivel más alto dentro de un sistema Linux, representado por `/`.

### Root user (or superuser)

Usuario con privilegios elevados que puede realizar cambios administrativos en prácticamente todo el sistema.

---

## S

### Shell

Intérprete de comandos que permite al usuario interactuar con el sistema operativo mediante instrucciones de texto.

### SQL (Structured Query Language)

Lenguaje utilizado para crear, consultar, modificar y administrar información almacenada en bases de datos.

### Standard error

Canal utilizado por el sistema operativo para enviar mensajes de error generados por comandos o procesos ejecutados desde el shell.

### Standard input

Canal mediante el cual un programa recibe información, normalmente desde el teclado o desde otro proceso.

### Standard output

Canal utilizado por un programa para devolver información al usuario, normalmente mostrada en la terminal.

### String data

Datos compuestos por una secuencia ordenada de caracteres, como letras, números y símbolos.

### Syntax

Conjunto de reglas que determina cómo debe estructurarse correctamente una instrucción dentro de un lenguaje informático.

---

## U

### Ubuntu

Distribución de Linux de código abierto, orientada a la facilidad de uso y ampliamente utilizada en computadores personales, servidores, desarrollo y ciberseguridad.

### Unified Extensible Firmware Interface (UEFI)

Firmware utilizado para inicializar el hardware y comenzar el proceso de arranque del sistema operativo. Es el sucesor moderno del BIOS.

### User

Persona que interactúa con un computador, sistema operativo, aplicación o recurso informático.

### User interface

Medio mediante el cual un usuario interactúa y controla las funciones de un sistema operativo o aplicación.

---

## V

### Virtual machine (VM)

Representación virtual de un computador físico que utiliza software para ejecutar un sistema operativo y sus aplicaciones dentro de otro sistema.

---

## W

### Wildcard

Carácter especial utilizado en búsquedas para representar uno o varios caracteres desconocidos.

En SQL, los principales comodines utilizados con `LIKE` son:

```sql
%   -- Representa cero o más caracteres
_   -- Representa exactamente un carácter
```

**Ejemplo:**

```sql
WHERE username LIKE 'adm%'
```

Esta consulta encuentra valores que comienzan con `adm`.
