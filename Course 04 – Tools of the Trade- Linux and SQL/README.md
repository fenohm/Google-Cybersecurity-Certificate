# Course 04 – Tools of the Trade: Linux and SQL

## Descripción

En este curso aprendí los fundamentos de los sistemas operativos, con un enfoque en Linux y su uso dentro de la ciberseguridad. También aprendí a utilizar comandos de Linux desde el shell para administrar archivos, directorios y sistemas, además de comprender los fundamentos de las bases de datos y utilizar SQL para consultar y analizar información.

## Objetivos del curso

- Comprender los fundamentos de los sistemas operativos y su funcionamiento.
- Conocer los componentes y funciones principales de un sistema operativo.
- Comprender el funcionamiento y las características del sistema operativo Linux.
- Utilizar comandos de Linux desde el shell para realizar tareas de administración y análisis.
- Gestionar archivos y directorios mediante la línea de comandos.
- Comprender los fundamentos de las bases de datos y su estructura.
- Utilizar SQL para consultar, filtrar y analizar información almacenada en bases de datos.
- Aplicar Linux y SQL en tareas relacionadas con la ciberseguridad.
