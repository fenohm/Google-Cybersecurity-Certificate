## Recursos de Linux

En este contenido aprendí a identificar y utilizar distintos recursos disponibles en Linux para **resolver problemas, consultar información y continuar aprendiendo de forma independiente**.

Linux cuenta con una amplia comunidad de usuarios que permite encontrar soluciones mediante documentación, foros y sitios de preguntas y respuestas. También existen herramientas integradas directamente en el sistema para consultar información sobre comandos.

### Comandos principales

* `man`: muestra el manual detallado de un comando y sus diferentes opciones.
* `apropos`: busca comandos y páginas de manual relacionadas con una palabra clave.
* `whatis`: proporciona una descripción breve de un comando.

### Conceptos clave

* **Documentación:** permite comprender el funcionamiento y las opciones de los comandos.
* **Solución de problemas:** la comunidad Linux es una fuente importante para encontrar soluciones a errores y dificultades.
* **Aprendizaje autónomo:** conocer herramientas como `man`, `apropos` y `whatis` permite investigar y aprender directamente desde el sistema.
* **Uso de recursos:** como futuro analista de ciberseguridad, saber buscar información y consultar documentación es fundamental para trabajar eficientemente con Linux.
