# 🖥️ CLI frente a GUI

Una GUI (Interfaz Gráfica de Usuario) permite interactuar con un computador mediante elementos visuales como ventanas, iconos y menús. En cambio, una CLI (Interfaz de Línea de Comandos) utiliza texto y comandos para realizar acciones en el sistema.

Característica	GUI	CLI
Interacción	Iconos, ventanas y menús	Comandos de texto
Facilidad de uso	Más sencilla para principiantes	Requiere aprender comandos
Eficiencia	Puede requerir varios pasos	Permite realizar tareas rápidamente
Automatización	Más limitada	Facilita la ejecución de múltiples tareas
Historial	Las acciones no siempre quedan registradas	Guarda los comandos utilizados

---

# 🔐 Importancia en ciberseguridad

La CLI es especialmente importante para los analistas de ciberseguridad, ya que permite ejecutar múltiples comandos de manera rápida y eficiente. En Linux, además, se puede consultar el historial de comandos, lo que resulta útil durante la respuesta a incidentes para verificar las acciones realizadas.

El historial también puede proporcionar información sobre las acciones que un atacante pudo haber ejecutado en un sistema comprometido, aunque no debe considerarse como la única fuente de evidencia.

---

# 📌 Conceptos clave
GUI: Interfaz gráfica que utiliza elementos visuales para interactuar con el sistema.
CLI: Interfaz basada en comandos de texto.
Historial de comandos: Registro de comandos ejecutados mediante la CLI.
Eficiencia: La CLI permite realizar tareas repetitivas y múltiples acciones de forma rápida.
Ciberseguridad: El uso de la CLI es fundamental para administrar sistemas, investigar incidentes y ejecutar herramientas de seguridad.
