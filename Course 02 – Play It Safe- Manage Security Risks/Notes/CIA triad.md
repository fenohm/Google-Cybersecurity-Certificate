# Tríada CID: Confidencialidad, Integridad y Disponibilidad

La **tríada CID** es un modelo fundamental de ciberseguridad utilizado para evaluar y gestionar los riesgos relacionados con la protección de datos y sistemas. Está compuesta por tres principios:

### 🔒 Confidencialidad

Garantiza que **solo las personas autorizadas puedan acceder a determinados datos o recursos**. Se puede reforzar mediante controles de acceso y el **principio de privilegio mínimo**, que limita los permisos de cada usuario a lo estrictamente necesario para realizar sus funciones.

### 🛡️ Integridad

Garantiza que los datos sean **correctos, auténticos y confiables**, evitando modificaciones no autorizadas. Puede protegerse mediante mecanismos como la **criptografía, cifrado, hashes y controles de integridad**.

### 🌐 Disponibilidad

Garantiza que los **usuarios autorizados puedan acceder a los datos y sistemas cuando los necesiten**. Para mantenerla se pueden implementar medidas como redundancia, copias de seguridad, mantenimiento y mecanismos de recuperación ante fallos.

### Importancia en ciberseguridad

La tríada CID sirve como base para diseñar **políticas, controles y sistemas de seguridad**, ayudando a las organizaciones a mantener una postura de seguridad adecuada y gestionar los riesgos que podrían afectar sus recursos y datos críticos.
