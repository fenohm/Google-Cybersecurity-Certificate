# Course 06 – Detection and Response

## Descripción

En este curso aprendí los fundamentos de la detección y respuesta ante incidentes de ciberseguridad, comprendiendo cómo los profesionales de seguridad monitorean sistemas y redes para identificar actividades sospechosas y posibles amenazas.

También estudié diferentes técnicas para analizar el tráfico de red, investigar incidentes de seguridad y responder ante ellos. Además, aprendí sobre el uso de herramientas como los sistemas de detección de intrusiones (*IDS*) y las plataformas de gestión de información y eventos de seguridad (*SIEM*) para recopilar, analizar y correlacionar eventos de seguridad.

---

## Objetivos del curso

* Comprender los fundamentos de la detección y respuesta ante incidentes.
* Comprender el proceso de monitoreo y análisis de redes.
* Identificar actividades anómalas y posibles incidentes de seguridad.
* Analizar el tráfico de red para detectar comportamientos sospechosos.
* Comprender las etapas de investigación y respuesta ante incidentes.
* Conocer diferentes herramientas utilizadas para la detección de amenazas.
* Comprender el funcionamiento y propósito de los sistemas de detección de intrusiones (*IDS*).
* Comprender el propósito de las plataformas de gestión de información y eventos de seguridad (*SIEM*).
* Analizar registros (*logs*) y eventos de seguridad para identificar posibles amenazas.
* Comprender cómo la información de diferentes fuentes puede utilizarse para investigar incidentes.
