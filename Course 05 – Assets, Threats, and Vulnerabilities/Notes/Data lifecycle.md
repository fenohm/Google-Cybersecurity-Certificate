# Ciclo de vida de los datos

## Resumen

El **Data Lifecycle (Ciclo de vida de los datos)** es un modelo utilizado para comprender cómo se gestionan y protegen los datos desde su creación hasta su eliminación.

La seguridad debe aplicarse durante todas las etapas para mantener la **Confidentiality, Integrity and Availability (CIA Triad)** de la información.

### Etapas del Data Lifecycle

El ciclo de vida de los datos generalmente contiene cinco etapas:

1. **Collect (Recopilar):** Obtención de datos desde fuentes internas o externas.
2. **Store (Almacenar):** Guardar los datos de forma segura en sistemas, bases de datos u otros medios.
3. **Use (Utilizar):** Procesar o utilizar los datos para las actividades de la organización.
4. **Archive (Archivar):** Conservar información que ya no se utiliza activamente, pero que debe mantenerse disponible.
5. **Destroy (Destruir):** Eliminar los datos cuando ya no son necesarios, evitando su recuperación o acceso no autorizado.

Los controles de seguridad deben considerar cada una de estas etapas.

### Data Governance

El **Data Governance (Gobierno de datos)** es el conjunto de procesos y políticas que determinan cómo una organización administra y protege su información.

Busca garantizar que los datos sean:

* Privados.
* Precisos.
* Seguros.
* Disponibles cuando sean necesarios.
* Utilizados de acuerdo con las políticas de la organización.

Dentro del gobierno de datos existen diferentes responsabilidades:

* **Data Owner:** Persona que determina quién puede acceder, modificar, utilizar o eliminar determinados datos.
* **Data Custodian:** Persona o entidad responsable de almacenar, transportar y manejar los datos de forma segura.
* **Data Administrator:** Persona o equipo encargado de implementar y mantener las políticas de gobierno de datos.

### Información protegida

No todos los datos tienen el mismo nivel de sensibilidad. Algunos tipos de información requieren controles de seguridad y privacidad específicos.

* **PII (Personally Identifiable Information):** Información que puede utilizarse para identificar, contactar o localizar a una persona.
* **PHI (Protected Health Information):** Información relacionada con la salud o estado médico de una persona. En Estados Unidos está relacionada con regulaciones como **HIPAA**.
* **SPII (Sensitive Personally Identifiable Information):** Información personal especialmente sensible que requiere controles de acceso más estrictos, como credenciales de acceso o información bancaria.

El acceso a este tipo de información debe limitarse únicamente a las personas que realmente lo necesitan.

## Puntos clave

* El **Data Lifecycle** permite gestionar y proteger la información durante todas sus etapas.
* Sus cinco etapas principales son **Collect, Store, Use, Archive y Destroy**.
* **Data Governance** establece políticas y responsabilidades para gestionar los datos de forma segura.
* El **Data Owner** determina cómo se puede utilizar la información.
* El **Data Custodian** se encarga de proteger y manejar los datos.
* El **Data Administrator** implementa las políticas de gobierno de datos.
* **PII, PHI y SPII** son tipos de información que requieren especial protección.
* La seguridad de los datos debe mantenerse durante todo su ciclo de vida para proteger la **Confidentiality, Integrity and Availability**.
