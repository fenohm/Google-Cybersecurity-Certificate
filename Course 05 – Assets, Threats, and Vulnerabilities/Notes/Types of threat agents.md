# Tipos de agentes de amenazas

## Resumen

Un **Threat Actor (Agente de amenaza)** es una persona o grupo que representa un riesgo para la seguridad de una organización. Puede actuar de forma intencional o accidental y puede encontrarse tanto dentro como fuera de la organización.

Comprender **quién puede atacar, por qué lo hace y cómo podría obtener acceso** permite anticiparse a posibles amenazas y proteger mejor la superficie de ataque.

## Tipos de Threat Actors

Los agentes de amenaza pueden clasificarse según sus motivaciones:

* **Competitors:** empresas rivales que podrían beneficiarse de obtener información de otra organización.
* **Nation-State Actors:** agencias o grupos relacionados con gobiernos que pueden realizar actividades de espionaje o recopilación de información.
* **Criminal Syndicates:** grupos organizados que buscan obtener beneficios económicos mediante actividades delictivas.
* **Insider Threats:** personas que tienen o tuvieron acceso autorizado a los recursos de una organización. Pueden provocar incidentes accidentalmente o de forma intencional.
* **Shadow IT:** uso de tecnologías o servicios que no están aprobados o controlados por el área de TI. Por ejemplo, utilizar un correo personal para actividades laborales.

## Tipos de hackers

El término **Hacker** es bastante amplio y no describe por sí solo las intenciones de una persona.

### Unauthorized Hackers

Los **Unauthorized Hackers** utilizan sus conocimientos para obtener acceso no autorizado y cometer actividades maliciosas.

Dentro de este grupo pueden existir los **Script Kiddies**, personas con conocimientos técnicos limitados que utilizan herramientas o código creado por otros.

### Authorized Hackers

Los **Authorized Hackers**, también llamados hackers éticos, trabajan con autorización para encontrar vulnerabilidades y mejorar la seguridad.

Algunos ejemplos son:

* Pentesters.
* Equipos internos de seguridad.
* Consultores externos.
* Investigadores que participan en **Bug Bounty Programs**.

### Semi-authorized Hackers

Los **Semi-authorized Hackers** pueden realizar actividades que infringen ciertas normas o autorizaciones, pero no necesariamente buscan causar daños.

Un ejemplo son los **Hacktivists**, que utilizan técnicas de hacking para promover objetivos políticos o sociales.

## Advanced Persistent Threat (APT)

Una **Advanced Persistent Threat (APT)** es una amenaza en la que un atacante mantiene acceso no autorizado a un sistema durante un periodo prolongado.

Las APT suelen caracterizarse por:

* Mantenerse ocultas durante largos períodos.
* Recopilar información de manera progresiva.
* Utilizar técnicas avanzadas.
* Buscar objetivos de alto valor.

El concepto suele asociarse con **Nation-State Actors** y grupos patrocinados por gobiernos, aunque las organizaciones privadas también pueden ser objetivos.

## Attack Vectors

Un **Attack Vector (Vector de ataque)** es el medio o método utilizado por un agente de amenaza para obtener acceso a un sistema, red o información.

Algunos vectores comunes son:

* **Direct Access:** acceso físico a un dispositivo o sistema.
* **Removable Media:** dispositivos extraíbles como unidades USB.
* **Social Media:** plataformas utilizadas para comunicación o distribución de contenido malicioso.
* **Email:** correos electrónicos utilizados, por ejemplo, para phishing o distribución de malware.
* **Wireless Networks:** redes inalámbricas vulnerables o comprometidas.
* **Cloud Services:** servicios y recursos alojados en la nube.
* **Supply Chain:** proveedores o terceros que pueden convertirse en una vía de acceso a la organización.

La relación entre el agente de amenaza y el vector utilizado puede ayudar a determinar qué controles de seguridad deberían reforzarse.

## Puntos clave

* Un **Threat Actor** puede ser una persona, grupo u organización que representa un riesgo para los recursos.
* No todos los agentes de amenaza tienen intenciones maliciosas; también existen amenazas internas accidentales.
* Los hackers pueden clasificarse según su autorización e intención.
* Un **APT** mantiene acceso a un objetivo durante un período prolongado y suele buscar información de alto valor.
* Un **Attack Vector** es el medio utilizado para acceder a un sistema o recurso.
* Los vectores pueden incluir correo electrónico, USB, redes inalámbricas, servicios cloud y cadenas de suministro.
* Comprender la **motivación + capacidad + vector de ataque** ayuda a desarrollar una mejor mentalidad defensiva.
