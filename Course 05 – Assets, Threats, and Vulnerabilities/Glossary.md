# Glossary - Course 05
---

## A

### Access controls

Controles de seguridad que gestionan el acceso, la autorización y la responsabilidad sobre la información.

### Adware

Tipo de software legítimo que, en ocasiones, se utiliza para mostrar anuncios digitales dentro de aplicaciones.

### Advanced persistent threat (APT)

Situación en la que un actor de amenazas mantiene acceso no autorizado a un sistema durante un período prolongado.

### Algorithm

Conjunto de reglas o instrucciones utilizadas para resolver un problema o realizar una tarea.

### Angler phishing

Técnica en la que los atacantes se hacen pasar por representantes de servicio al cliente, generalmente a través de redes sociales.

### Application programming interface (API) token

Pequeño bloque de código cifrado que contiene información utilizada para identificar o autenticar a un usuario o aplicación.

### Asset

Elemento que posee valor para una organización y que necesita ser protegido.

### Asset classification

Proceso de etiquetar o clasificar los activos según su nivel de sensibilidad e importancia para una organización.

### Asset inventory

Catálogo de los activos que una organización necesita identificar y proteger.

### Asset management

Proceso de realizar un seguimiento de los activos y de los riesgos que pueden afectarlos.

### Asymmetric encryption

Método de cifrado que utiliza un par de claves, una pública y otra privada, para cifrar y descifrar información.

### Attack surface

Características y áreas de un sistema, red o aplicación desde las cuales podría originarse un ataque.

### Attack tree

Diagrama que representa y relaciona las posibles amenazas con los activos que podrían ser afectados.

### Attack vector

Ruta o método que utilizan los atacantes para atravesar las defensas de seguridad y acceder a un sistema.

---

## B

### Baiting

Táctica de ingeniería social que utiliza una oferta o elemento atractivo para convencer a una persona de comprometer su seguridad.

### Basic auth

Tecnología utilizada para establecer la solicitud de un usuario para acceder a un servidor mediante autenticación básica.

### Bit

Unidad más pequeña de medida de datos en un computador, que puede representar un valor de `0` o `1`.

### Botnet

Conjunto de computadores infectados con malware que se encuentran bajo el control de un único actor de amenazas, conocido como *bot-herder*.

### Brute force attack

Proceso de prueba y error utilizado para descubrir información privada, como contraseñas o credenciales.

### Bug bounty

Programa que incentiva a hackers independientes a encontrar y reportar vulnerabilidades en sistemas o aplicaciones.

---

## C

### Cipher

Algoritmo utilizado para cifrar información y convertirla en un formato que no pueda ser comprendido fácilmente por personas no autorizadas.

### Common Vulnerabilities and Exposures (CVE) list

Diccionario de acceso público que contiene información sobre vulnerabilidades y exposiciones de seguridad conocidas.

### Common Vulnerability Scoring System (CVSS)

Sistema de medición utilizado para determinar la gravedad de una vulnerabilidad.

### Compliance

Proceso de cumplir con estándares internos y regulaciones externas aplicables a una organización.

### Computer virus

Ver **Virus**.

### Cross-site scripting (XSS)

Tipo de ataque de inyección que introduce código malicioso en un sitio web o aplicación web vulnerable.

### Cryptojacking

Tipo de malware que instala software para utilizar los recursos de un dispositivo con el objetivo de minar criptomonedas de manera no autorizada.

### Cryptographic key

Mecanismo utilizado en procesos criptográficos para cifrar o descifrar información.

### Cryptography

Proceso de transformar información a un formato que no pueda ser comprendido por personas no autorizadas.

### CVE Numbering Authority (CNA)

Organización autorizada que analiza y distribuye información sobre vulnerabilidades elegibles para recibir identificadores CVE.

---

## D

### Data

Información que es traducida, procesada o almacenada por un computador.

### Data at rest

Datos que no están siendo accedidos ni utilizados actualmente.

### Data in transit

Datos que se encuentran viajando de un punto a otro a través de una red o sistema.

### Data in use

Datos que están siendo accedidos o utilizados por uno o más usuarios o procesos.

### Data custodian

Persona, organización o sistema responsable del manejo, transporte y almacenamiento seguro de la información.

### Data owner

Persona responsable de decidir quién puede acceder, editar, utilizar o eliminar determinada información.

### Defense in depth

Enfoque de seguridad basado en múltiples capas de protección para reducir los riesgos y vulnerabilidades de un sistema.

### Digital certificate

Archivo digital que permite verificar la identidad del propietario de una clave pública.

### DOM-based XSS attack

Tipo de ataque XSS en el que un script malicioso se encuentra en la página web que carga el navegador y modifica el Document Object Model (DOM).

### Dropper

Tipo de malware que contiene código malicioso y cuya función es entregarlo e instalarlo en un sistema objetivo.

---

## E

### Encryption

Proceso de convertir datos desde un formato legible a un formato codificado para evitar que personas no autorizadas puedan comprenderlos.

### Exploit

Método o código utilizado para aprovechar una vulnerabilidad de un sistema, aplicación o dispositivo.

### Exposure

Error, debilidad o situación que puede ser aprovechada por una amenaza para comprometer un sistema o sus datos.

---

## F

### Fileless malware

Tipo de malware que no necesita ser instalado como un archivo tradicional, ya que utiliza programas legítimos que ya se encuentran instalados en el computador para realizar actividades maliciosas.

---

## H

### Hacker

Persona que utiliza computadores para obtener acceso a sistemas, redes o datos.

### Hash collision

Situación en la que dos entradas diferentes producen el mismo valor hash.

### Hash function

Algoritmo que transforma datos de entrada en un valor hash de longitud determinada.

### Hash table

Estructura de datos utilizada para almacenar y consultar valores hash.

---

## I

### Identity and access management (IAM)

Conjunto de procesos y tecnologías que permite a las organizaciones administrar las identidades digitales y controlar el acceso a sus recursos.

### Information privacy

Protección de la información frente al acceso, uso o distribución no autorizados.

### Information security (InfoSec)

Práctica de proteger los datos, independientemente de su estado, frente a accesos o usos no autorizados.

### Injection attack

Ataque en el que se introduce código o comandos maliciosos en una aplicación vulnerable.

### Input validation

Proceso mediante el cual un programa verifica que los datos introducidos por usuarios u otros programas sean válidos y seguros.

### Intrusion detection system (IDS)

Aplicación o sistema que supervisa la actividad de un sistema o red y genera alertas ante posibles intrusiones.

---

## L

### Loader

Tipo de malware cuya función es descargar código malicioso desde una fuente externa e instalarlo en un sistema objetivo.

---

## M

### Malware

Software diseñado para dañar, alterar, obtener acceso no autorizado o afectar negativamente dispositivos, sistemas o redes.

### MITRE

Organización compuesta por centros de investigación y desarrollo sin fines de lucro que proporciona recursos y conocimientos relacionados con la ciberseguridad, entre otros ámbitos.

### Multi-factor authentication (MFA)

Tecnología que requiere al menos dos formas diferentes de identificación para verificar la identidad de un usuario.

---

## N

### National Institute of Standards and Technology (NIST) Cybersecurity Framework (CSF)

Marco voluntario compuesto por estándares, directrices y buenas prácticas destinadas a ayudar a las organizaciones a gestionar los riesgos de ciberseguridad.

### Non-repudiation

Principio que garantiza que la autenticidad o participación asociada a una información o acción no pueda ser negada posteriormente.

---

## O

### OAuth

Protocolo de autorización de estándar abierto que permite compartir un acceso específico entre aplicaciones sin necesidad de compartir directamente las credenciales del usuario.

---

## P

### Process of Attack Simulation and Threat Analysis (PASTA)

Marco de modelado de amenazas utilizado para analizar riesgos y amenazas de seguridad en diferentes tipos de organizaciones.

### Payment Card Industry Data Security Standards (PCI DSS)

Conjunto de estándares de seguridad creados por organizaciones de la industria financiera para proteger los datos de tarjetas de pago.

### Personally identifiable information (PII)

Cualquier información que pueda utilizarse para identificar o inferir la identidad de una persona.

### Phishing

Uso de comunicaciones digitales engañosas para convencer a las personas de revelar información confidencial o instalar software malicioso.

### Phishing kit

Conjunto de herramientas de software utilizadas para realizar una campaña de phishing.

### Policy

Conjunto de reglas establecidas para reducir riesgos y proteger la información de una organización.

### Potentially unwanted application (PUA)

Tipo de software no deseado que puede incluirse junto con programas legítimos y que puede mostrar anuncios, ralentizar un dispositivo o instalar otro software.

### Prepared statement

Técnica de programación que prepara las instrucciones SQL antes de enviarlas o ejecutarlas en una base de datos.

### Principle of least privilege

Principio que establece que los usuarios deben recibir únicamente el nivel mínimo de acceso y autorización necesario para realizar una tarea o función.

### Procedures

Instrucciones paso a paso utilizadas para realizar una tarea específica de seguridad.

### Protected health information (PHI)

Información relacionada con la salud física o mental pasada, presente o futura de una persona.

### Public key infrastructure (PKI)

Marco de cifrado y gestión de claves utilizado para proteger el intercambio de información en línea.

---

## Q

### Quid pro quo

Tipo de técnica de baiting que intenta convencer a una persona de que recibirá una recompensa a cambio de proporcionar acceso, información o dinero.

---

## R

### Rainbow table

Archivo que contiene valores hash previamente calculados y sus correspondientes textos originales.

### Ransomware

Tipo de ataque malicioso en el que los atacantes cifran los datos de una organización y exigen un pago para restaurar el acceso.

### Regulations

Reglas establecidas por un gobierno u otra autoridad para controlar la forma en que se realiza una actividad.

### Reflected XSS attack

Tipo de ataque en el que un script malicioso es enviado a un servidor y se activa cuando el servidor lo incluye en su respuesta.

### Risk

Cualquier situación que pueda afectar la confidencialidad, integridad o disponibilidad de un activo.

### Rootkit

Tipo de malware que proporciona acceso remoto y privilegios administrativos a un computador.

---

## S

### Salting

Medida de seguridad adicional que se utiliza para fortalecer las funciones hash mediante la incorporación de datos adicionales antes de realizar el hashing.

### Scareware

Tipo de malware que utiliza tácticas destinadas a asustar o alarmar a los usuarios para conseguir que infecten sus dispositivos.

### Security assessment

Evaluación utilizada para determinar qué tan resistentes son las implementaciones de seguridad actuales frente a posibles amenazas.

### Security audit

Revisión de los controles, políticas y procedimientos de seguridad de una organización en comparación con un conjunto de requisitos o expectativas.

### Security controls

Medidas de protección diseñadas para reducir riesgos de seguridad específicos.

### Security hardening

Proceso de fortalecer un sistema para reducir sus vulnerabilidades y disminuir su superficie de ataque.

### Separation of duties

Principio que establece que los usuarios no deben recibir niveles de autorización que les permitan abusar o hacer un uso indebido de un sistema.

### Session

Secuencia de solicitudes y respuestas HTTP asociadas con un mismo usuario durante una interacción con un sistema.

### Session cookie

Token utilizado por los sitios web para validar una sesión y determinar cuánto tiempo debe permanecer activa.

### Session hijacking

Situación en la que un atacante obtiene el identificador de sesión legítimo de un usuario para acceder a su sesión.

### Session ID

Token único utilizado para identificar a un usuario y su dispositivo mientras accede a un sistema.

### Single sign-on (SSO)

Tecnología que permite utilizar una única autenticación para acceder a múltiples aplicaciones o servicios.

### Smishing

Uso de mensajes de texto para engañar a los usuarios con el objetivo de obtener información confidencial o hacerse pasar por una fuente conocida.

### Social engineering

Técnica de manipulación que explota los errores humanos para obtener información privada, acceso o recursos.

### Spear phishing

Ataque de phishing dirigido específicamente a una persona o grupo de usuarios y que aparenta provenir de una fuente confiable.

### Spyware

Tipo de malware utilizado para recopilar información de los usuarios sin su consentimiento.

### SQL (Structured Query Language)

Lenguaje de programación utilizado para crear, interactuar con y solicitar información de una base de datos.

### SQL injection

Ataque que introduce consultas SQL inesperadas o maliciosas en una base de datos mediante una aplicación vulnerable.

### Standards

Referencias que proporcionan orientación sobre cómo establecer políticas y prácticas de seguridad.

### Stored XSS attack

Tipo de ataque XSS en el que un script malicioso se inserta directamente en un servidor o almacenamiento y posteriormente se entrega a los usuarios.

### Symmetric encryption

Método de cifrado que utiliza una única clave secreta para cifrar y descifrar información.

---

## T

### Tailgating

Táctica de ingeniería social en la que una persona no autorizada sigue a una persona autorizada para ingresar a un área restringida.

### Threat

Cualquier circunstancia o evento que pueda afectar negativamente a los activos de una organización.

### Threat actor

Persona o grupo que representa un riesgo para la seguridad de un sistema, red u organización.

### Threat modeling

Proceso de identificar los activos, sus vulnerabilidades y la forma en que cada uno de ellos está expuesto a posibles amenazas.

### Trojan horse

Tipo de malware que aparenta ser un archivo o programa legítimo para engañar al usuario y conseguir que lo ejecute.

---

## U

### User provisioning

Proceso de crear y mantener la identidad digital y los permisos de acceso de un usuario.

---

## V

### Virus

Código malicioso diseñado para interferir con las operaciones de un computador y causar daños a los datos o al software.

### Vishing

Uso de comunicaciones de voz o llamadas telefónicas para obtener información confidencial o hacerse pasar por una fuente conocida.

### Vulnerability

Debilidad de un sistema, aplicación, dispositivo o red que puede ser aprovechada por una amenaza.

### Vulnerability scanner

Software que compara automáticamente las vulnerabilidades conocidas con las tecnologías presentes en una red para identificar posibles vulnerabilidades.

### Vulnerability assessment

Proceso de revisión interna utilizado para evaluar las vulnerabilidades de los sistemas de seguridad de una organización.

### Vulnerability management

Proceso de identificar, evaluar y corregir vulnerabilidades para reducir los riesgos de seguridad.

---

## W

### Watering hole attack

Tipo de ataque en el que un actor de amenazas compromete un sitio web que suele ser visitado por un grupo específico de usuarios.

### Whaling

Tipo de ataque de spear phishing dirigido específicamente a personas de alto rango dentro de una organización, como ejecutivos.

### Web-based exploits

Código o comportamiento malicioso utilizado para aprovechar fallas de programación en una aplicación web.

### Worm

Tipo de malware capaz de duplicarse y propagarse automáticamente entre sistemas.

---

## Z

### Zero-day

Vulnerabilidad o exploit que anteriormente era desconocido y para el cual normalmente aún no existe una solución o parche disponible.
