# Glossary - Course 05
---

### A

**Access controls:** Controles de seguridad que administran el acceso, la autorización y la responsabilidad sobre la información.

**Adware:** Tipo de software legítimo que a veces se utiliza para mostrar anuncios digitales en las aplicaciones.

**Advanced persistent threat (APT):** Situación en la que un actor de amenazas mantiene acceso no autorizado a un sistema durante un período prolongado.

**Algorithm:** Conjunto de reglas utilizadas para resolver un problema.

**Angler phishing:** Técnica en la que los atacantes se hacen pasar por representantes de servicio al cliente en redes sociales.

**Application programming interface (API) token:** Pequeño bloque de código cifrado que contiene información sobre un usuario.

**Asset:** Elemento que una organización considera que tiene valor.

**Asset classification:** Práctica de etiquetar los activos según su nivel de sensibilidad e importancia para una organización.

**Asset inventory:** Catálogo de los activos que necesitan ser protegidos.

**Asset management:** Proceso de seguimiento de los activos y de los riesgos que pueden afectarlos.

**Asymmetric encryption:** Uso de un par de claves, una pública y una privada, para cifrar y descifrar datos.

**Attack surface:** Características y elementos de las áreas desde las cuales puede originarse un ataque.

**Attack tree:** Diagrama que relaciona las amenazas con los activos.

**Attack vector:** Vías o métodos que utilizan los atacantes para penetrar las defensas de seguridad.

---

### B

**Baiting:** Táctica de ingeniería social que atrae o tienta a las personas para que comprometan su seguridad.

**Basic auth:** Tecnología utilizada para establecer la solicitud de un usuario para acceder a un servidor.

**Bit:** Unidad más pequeña de medición de datos en un computador.

**Botnet:** Conjunto de computadores infectados con malware que se encuentran bajo el control de un único actor de amenazas, conocido como “bot-herder”.

**Brute force attack:** Proceso de prueba y error utilizado para descubrir información privada.

**Bug bounty:** Programas que incentivan a hackers independientes a encontrar y reportar vulnerabilidades.

---

### C

**Cipher:** Algoritmo que cifra información.

**Common Vulnerabilities and Exposures (CVE®) list:** Diccionario de acceso público que contiene vulnerabilidades y exposiciones conocidas.

**Common Vulnerability Scoring System (CVSS):** Sistema de medición que asigna una puntuación a la gravedad de una vulnerabilidad.

**Compliance:** Proceso de cumplir con estándares internos y regulaciones externas.

**Computer virus:** Ver **Virus**.

**Cross-site scripting (XSS):** Ataque de inyección que introduce código en un sitio web o aplicación web vulnerable.

**Cryptojacking:** Tipo de malware que instala software para minar criptomonedas de manera ilegal.

**Cryptographic key:** Mecanismo utilizado para descifrar texto cifrado.

**Cryptography:** Proceso de transformar información a un formato que las personas no autorizadas no puedan comprender.

**CVE Numbering Authority (CNA):** Organización que se ofrece voluntariamente para analizar y distribuir información sobre CVE elegibles.

---

### D

**Data:** Información que ha sido traducida, procesada o almacenada por un computador.

**Data at rest:** Datos que actualmente no están siendo accedidos.

**Data in transit:** Datos que se están trasladando de un punto a otro.

**Data in use:** Datos que están siendo utilizados o accedidos por uno o más usuarios.

**Data custodian:** Persona o elemento responsable del manejo, transporte y almacenamiento seguro de la información.

**Data owner:** Persona que decide quién puede acceder, editar, utilizar o destruir determinada información.

**Defense in depth:** Enfoque basado en múltiples capas de protección para la gestión de vulnerabilidades y la reducción del riesgo.

**Digital certificate:** Archivo que verifica la identidad del propietario de una clave pública.

**DOM-based XSS attack:** Situación en la que un script malicioso está presente en una página web que carga el navegador.

**Dropper:** Tipo de malware que contiene código malicioso y que lo entrega e instala en un sistema objetivo.

---

### E

**Encryption:** Proceso de convertir datos desde un formato legible a un formato codificado.

**Exploit:** Método utilizado para aprovechar una vulnerabilidad.

**Exposure:** Error o debilidad que puede ser aprovechado por una amenaza.

---

### F

**Fileless malware:** Malware que no necesita ser instalado directamente por el usuario, ya que utiliza programas legítimos que ya están instalados para infectar un computador.

---

### H

**Hacker:** Persona que utiliza computadores para obtener acceso a sistemas, redes o datos.

**Hash collision:** Situación en la que diferentes entradas producen el mismo valor hash.

**Hash function:** Algoritmo que produce un código que no puede ser descifrado.

**Hash table:** Estructura de datos utilizada para almacenar y consultar valores hash.

---

### I

**Identity and access management (IAM):** Conjunto de procesos y tecnologías que ayuda a las organizaciones a administrar las identidades digitales dentro de su entorno.

**Information privacy:** Protección de los datos frente al acceso y distribución no autorizados.

**Information security (InfoSec):** Práctica de mantener los datos, independientemente de su estado, protegidos de usuarios no autorizados.

**Injection attack:** Código malicioso insertado en una aplicación vulnerable.

**Input validation:** Programación que valida las entradas provenientes de usuarios y otros programas.

**Intrusion detection system (IDS):** Aplicación que monitorea la actividad de un sistema y genera alertas ante posibles intrusiones.

---

### L

**Loader:** Tipo de malware que descarga código malicioso desde una fuente externa y lo instala en un sistema objetivo.

---

### M

**Malware:** Software diseñado para dañar dispositivos o redes.

**MITRE:** Conjunto de centros de investigación y desarrollo sin fines de lucro.

**Multi-factor authentication (MFA):** Tecnología que requiere al menos dos formas distintas de identificación.

---

### N

**National Institute of Standards and Technology (NIST) Cybersecurity Framework (CSF):** Marco voluntario compuesto por estándares, directrices y buenas prácticas para gestionar los riesgos de ciberseguridad.

**Non-repudiation:** Concepto que establece que la autenticidad de una información no puede ser negada.

---

### O

**OAuth:** Protocolo de autorización de estándar abierto que permite compartir accesos específicos entre aplicaciones.
