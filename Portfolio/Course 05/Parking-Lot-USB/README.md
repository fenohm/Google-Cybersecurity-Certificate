# Parking lot USB exercise

## Overview

This exercise analyzes a potential **USB baiting attack** in a hospital environment.

The scenario focuses on the risks of connecting an unknown USB device and the possible exposure of personal and sensitive work-related information.

## Topics

* USB Baiting
* Social Engineering
* Malware
* PII (Personally Identifiable Information)
* Risk Analysis
* Security Controls
* Security Awareness

## Skills Demonstrated

* Identifying potential security risks
* Analyzing an attacker's mindset
* Identifying sensitive information
* Proposing technical, operational, and managerial controls
* Applying cybersecurity concepts to a real-world scenario
