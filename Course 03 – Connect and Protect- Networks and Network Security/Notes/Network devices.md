# Dispositivos de red

Los **dispositivos de red** permiten que los equipos y sistemas se comuniquen entre sí mediante conexiones cableadas o inalámbricas. Los dispositivos intercambian información mediante **paquetes de datos**, que contienen información sobre el origen y destino de los datos.

## Principales dispositivos de red

**Dispositivos finales:** Ordenadores, portátiles, teléfonos y tabletas que se conectan a la red. Cada dispositivo posee una dirección **MAC** y una dirección **IP**, además de una interfaz de red para enviar y recibir datos.

**Firewall (Cortafuegos):** Dispositivo de seguridad que supervisa y controla el tráfico entrante y saliente según reglas establecidas. Actúa como una primera línea de defensa entre una red interna y redes externas como Internet.

**Servidor:** Proporciona información y servicios a otros dispositivos llamados clientes. Algunos ejemplos son servidores **DNS**, servidores de archivos y servidores de correo.

**Hub (Concentrador):** Dispositivo que conecta varios equipos y repite los datos hacia todos sus puertos. Debido a esto, presenta riesgos de seguridad y ha sido reemplazado en gran medida por los switches.

**Switch (Conmutador):** Conecta dispositivos dentro de una red local y reenvía los paquetes únicamente hacia el dispositivo de destino. Utiliza una tabla de direcciones **MAC** para determinar dónde enviar cada paquete, mejorando el rendimiento y la seguridad de la red.

**Router (Enrutador):** Conecta diferentes redes y dirige los paquetes utilizando las direcciones **IP** de destino. Permite la comunicación entre dispositivos de distintas redes y puede incorporar funciones de firewall.

**Módem:** Conecta una red doméstica u oficina con el proveedor de servicios de Internet (ISP), convirtiendo las señales utilizadas por la conexión física para permitir el acceso a Internet.

**Wireless Access Point (Punto de acceso inalámbrico):** Proporciona conectividad inalámbrica mediante Wi-Fi, permitiendo que dispositivos compatibles se conecten a la red mediante ondas de radio.

## Modelo cliente-servidor

En el modelo **cliente-servidor**, los clientes solicitan información o servicios y los servidores procesan estas solicitudes y proporcionan los recursos solicitados.

**Ejemplo:**

> Cliente → Solicitud → Servidor → Respuesta → Cliente

## Diagramas de red

Los **diagramas de red** son representaciones visuales de la arquitectura de una red. Muestran los dispositivos existentes y las conexiones entre ellos.

Para un analista de seguridad, los diagramas de red permiten comprender cómo está estructurada una organización, identificar posibles puntos vulnerables y desarrollar estrategias para proteger la infraestructura.

## Puntos clave

* Los **switches** conectan dispositivos dentro de una red y utilizan direcciones MAC para reenviar paquetes.
* Los **routers** conectan diferentes redes y utilizan direcciones IP para dirigir el tráfico.
* Los **firewalls** controlan el tráfico y ayudan a proteger la red.
* Los **servidores** proporcionan servicios y recursos a los clientes.
* Los **access points** permiten conectar dispositivos mediante Wi-Fi.
* Los **diagramas de red** ayudan a los analistas a comprender y proteger la arquitectura de una organización.
