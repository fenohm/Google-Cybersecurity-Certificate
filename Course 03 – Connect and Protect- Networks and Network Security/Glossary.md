# Glossary – Course 03
---

## A

### Active packet sniffing

Tipo de ataque en el que los paquetes de datos son manipulados mientras están en tránsito.

### Address Resolution Protocol (ARP)

Protocolo utilizado para determinar la dirección MAC del siguiente router o dispositivo por el que debe pasar un paquete.

---

## B

### Bandwidth

Capacidad máxima de transmisión de datos de una red, medida en bits por segundo.

### Baseline configuration

Conjunto documentado de especificaciones de un sistema que sirve como referencia para futuras implementaciones, versiones y actualizaciones.

### Bluetooth

Tecnología utilizada para la comunicación inalámbrica entre dispositivos físicos cercanos.

### Botnet

Conjunto de computadoras infectadas con malware que están bajo el control de un único actor de amenazas, conocido como *bot herder*.

---

## C

### Cloud-based firewalls

Firewalls de software alojados y administrados por un proveedor de servicios en la nube.

### Cloud computing

Práctica de utilizar servidores, aplicaciones y servicios de red remotos alojados en Internet en lugar de dispositivos físicos locales.

### Cloud network

Conjunto de servidores o computadoras que almacenan recursos y datos en centros de datos remotos accesibles mediante Internet.

### Controlled zone

Subred que protege la red interna frente a la zona no controlada.

---

## D

### Data packet

Unidad básica de información que viaja de un dispositivo a otro dentro de una red.

### Denial of Service (DoS) attack

Ataque dirigido contra una red o servidor que lo sobrecarga con tráfico de red para impedir su funcionamiento normal.

### Distributed Denial of Service (DDoS) attack

Tipo de ataque DoS que utiliza múltiples dispositivos o servidores ubicados en diferentes lugares para inundar el objetivo con tráfico no deseado.

### Domain Name System (DNS)

Protocolo de red que traduce nombres de dominio de Internet en direcciones IP.

---

## E

### Encapsulation

Proceso utilizado por una VPN para proteger los datos envolviendo información sensible dentro de otros paquetes de datos.

---

## F

### File Transfer Protocol (FTP)

Protocolo utilizado para transferir archivos de un dispositivo a otro a través de una red.

### Firewall

Dispositivo o software de seguridad de red que supervisa y controla el tráfico que entra o sale de una red.

---

## H

### Hardware

Componentes físicos de una computadora.

### Hub

Dispositivo de red que transmite la información recibida a todos los dispositivos conectados a la red.

### Hypertext Transfer Protocol (HTTP)

Protocolo de la capa de aplicación que permite la comunicación entre clientes y servidores web.

### Hypertext Transfer Protocol Secure (HTTPS)

Protocolo de red que proporciona una comunicación segura entre clientes y servidores mediante cifrado.

---

## I

### Identity and Access Management (IAM)

Conjunto de procesos y tecnologías que permite a las organizaciones administrar identidades digitales y controlar el acceso a sus recursos.

### IEEE 802.11 (Wi-Fi)

Conjunto de estándares que define la comunicación utilizada en redes LAN inalámbricas.

### Internet Control Message Protocol (ICMP)

Protocolo de Internet utilizado por los dispositivos para comunicar errores y otra información relacionada con la transmisión de datos en una red.

### Internet Control Message Protocol (ICMP) flood

Tipo de ataque DoS que consiste en enviar repetidamente paquetes de solicitud ICMP a un servidor para sobrecargarlo.

### Internet Protocol (IP)

Conjunto de estándares utilizados para direccionar y enrutar paquetes de datos mientras viajan entre dispositivos de una red.

### Internet Protocol (IP) address

Cadena única de caracteres utilizada para identificar la dirección de un dispositivo dentro de una red.

### IP spoofing

Ataque de red en el que un atacante modifica la dirección IP de origen de un paquete para hacerse pasar por un sistema autorizado y obtener acceso a una red.

---

## L

### Local Area Network (LAN)

Red que cubre un área geográfica pequeña, como una vivienda, escuela u oficina.

---

## M

### Media Access Control (MAC) address

Identificador alfanumérico único asignado a una interfaz de red física.

### Modem

Dispositivo que conecta el router con Internet y proporciona acceso a Internet a la LAN.

### Multi-factor Authentication (MFA)

Medida de seguridad que requiere que un usuario verifique su identidad utilizando dos o más métodos para acceder a un sistema o red.

---

## N

### Network

Grupo de dispositivos conectados entre sí para comunicarse y compartir recursos.

### Network log analysis

Proceso de examinar registros de red para identificar eventos relevantes o actividades sospechosas.

### Network protocols

Conjunto de reglas utilizadas por dos o más dispositivos para definir cómo se estructuran, transmiten y reciben los datos.

### Network segmentation

Técnica de seguridad que divide una red en diferentes segmentos para mejorar su organización, rendimiento y seguridad.

---

## O

### Operating System (OS)

Software que actúa como interfaz entre el hardware de una computadora y el usuario.

### Open Systems Interconnection (OSI) model

Modelo estandarizado que describe las siete capas utilizadas por los sistemas para comunicarse y transmitir datos a través de una red.

### On-path attack

Ataque en el que un actor malicioso se coloca entre dos partes que mantienen una conexión legítima para interceptar o modificar los datos en tránsito.

---

## P

### Packet sniffing

Práctica de capturar e inspeccionar paquetes de datos que circulan por una red.

### Passive packet sniffing

Tipo de ataque en el que un actor malicioso se conecta a un hub de red y observa el tráfico que circula por la red.

### Patch update

Actualización de software o del sistema operativo destinada a corregir vulnerabilidades de seguridad.

### Penetration testing

Ataque simulado utilizado para identificar vulnerabilidades en sistemas, redes, sitios web, aplicaciones y procesos.

### Ping of death

Tipo de ataque DoS que consiste en enviar un paquete ICMP excesivamente grande, superior a 64 KB, para provocar problemas en el sistema objetivo.

### Port

Ubicación lógica basada en software que permite organizar el envío y recepción de datos entre dispositivos y servicios de una red.

### Port filtering

Función de un firewall que permite o bloquea determinados números de puerto para limitar comunicaciones no deseadas.

### Proxy server

Servidor que recibe y reenvía las solicitudes de sus clientes hacia otros servidores.

---

## R

### Replay attack

Ataque de red en el que un actor malicioso intercepta un paquete de datos durante su transmisión y posteriormente lo retrasa o lo vuelve a enviar.

### Reverse proxy server

Servidor que regula y restringe el acceso desde Internet hacia servidores internos de una organización.

### Router

Dispositivo de red que conecta múltiples redes y dirige los paquetes de datos entre ellas.

---

## S

### Secure File Transfer Protocol (SFTP)

Protocolo seguro utilizado para transferir archivos entre dispositivos a través de una red.

### Secure Shell (SSH)

Protocolo de seguridad utilizado para establecer una conexión de línea de comandos segura con un sistema remoto.

### Security hardening

Proceso de fortalecer un sistema para reducir sus vulnerabilidades y su superficie de ataque.

### Security Information and Event Management (SIEM)

Aplicación que recopila y analiza registros para supervisar actividades importantes y eventos de seguridad dentro de una organización.

### Security zone

Segmento de una red empresarial utilizado para proteger la red interna frente a Internet y otras redes no confiables.

### Simple Network Management Protocol (SNMP)

Protocolo de red utilizado para supervisar y administrar dispositivos conectados a una red.

### Smurf attack

Ataque de red en el que un atacante utiliza la dirección IP de un usuario autorizado para inundarla con paquetes ICMP.

### Speed

Velocidad a la que un dispositivo puede enviar y recibir datos, medida en bits por segundo.

### Stateful

Tipo de firewall que mantiene un registro de la información que atraviesa el dispositivo y utiliza ese estado para filtrar amenazas.

### Stateless

Tipo de firewall que funciona mediante reglas predefinidas y no mantiene un registro del estado de las conexiones.

### Subnetting

Proceso de dividir una red en grupos lógicos más pequeños denominados subredes.

### Switch

Dispositivo de red que conecta dispositivos específicos y reenvía datos entre ellos.

### Synchronize (SYN) flood attack

Tipo de ataque DoS que simula conexiones TCP/IP y sobrecarga un servidor enviándole grandes cantidades de paquetes SYN.

---

## T

### TCP/IP model

Modelo utilizado para representar cómo se organizan, transmiten y reciben los datos a través de una red.

### Transmission Control Protocol (TCP)

Protocolo de comunicación que permite establecer una conexión entre dos dispositivos y transmitir datos de manera confiable.

### Transmission Control Protocol (TCP) 3-way handshake

Proceso de tres pasos utilizado para establecer una conexión TCP entre dos dispositivos de una red.

---

## U

### Uncontrolled zone

Parte de la red que se encuentra fuera del control directo de una organización.

### User Datagram Protocol (UDP)

Protocolo sin conexión que permite transmitir datos sin establecer previamente una conexión entre los dispositivos.

---

## V

### Virtual Private Network (VPN)

Servicio de seguridad de red que cifra los datos y puede ocultar la dirección IP pública y ubicación virtual del usuario al utilizar una red pública como Internet.

---

## W

### Wide Area Network (WAN)

Red que cubre una gran área geográfica, como una ciudad, región o país.

### Wi-Fi Protected Access (WPA)

Protocolo de seguridad inalámbrica utilizado para proteger las conexiones Wi-Fi y controlar el acceso de los dispositivos a una red.
