# Course 03 – Connect and Protect: Networks and Network Security

## Descripción

En este curso aprendí los fundamentos de las redes y la seguridad de redes, incluyendo la arquitectura de red, las operaciones de red, las principales amenazas y técnicas de intrusión, y las medidas utilizadas para proteger y fortalecer los sistemas y redes.

## Objetivos del curso

- Comprender los fundamentos de la arquitectura de red.
- Conocer cómo funcionan las operaciones y comunicaciones dentro de una red.
- Identificar amenazas, vulnerabilidades e intrusiones en una red.
- Comprender los principales protocolos y dispositivos de red.
- Conocer diferentes técnicas utilizadas para proteger las redes.
- Comprender el concepto de endurecimiento de seguridad (security hardening).
- Identificar medidas de seguridad para reducir los riesgos en una red.
